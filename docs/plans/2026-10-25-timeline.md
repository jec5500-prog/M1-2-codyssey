## 반드시 이 순서로 시작하는 이유

1. 기존 Render가 requirements 경로 오류로 기동도 못 하므로 실행 기반을 먼저 복구한다.
2. CORS 이름과 필수 저장 API를 맞춰 프론트가 붙을 계약을 고정한다.
3. 실제 데이터가 0건이므로 100건 이상과 독립 통계를 확보해야 AI 답변을 검증할 수 있다.
4. 저장과 AI가 정상일 때 UI 및 배포 전 흐름을 검수한다.
5. MCP는 동일 API를 쓰므로 검증된 API 위에 얇게 추가한다. 기능 검수 후 제출 근거를 모은다.
